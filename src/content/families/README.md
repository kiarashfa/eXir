# Families

Authored parametric formula pages: the Sour, the Highball, the Old Fashioned,
Steeped Infusions, Blended & Frozen.

One MDX file per family. Each carries a formula rendered through the same live
quantity machinery a drink uses, prose explaining what each slot does and what
moving the ratio costs, and a computed member list drawn from the `family`
references on the drinks themselves.

Descent is recorded on the drinks via `derivedFrom`, and must stay inside the
family — a chain that leaves one is a resemblance, not a lineage.
