# Preparations

An ingredient you make: syrups, cordials, shrubs, orgeats, infusions,
tinctures, cold-brew concentrate, spice mixes.

One MDX file per preparation. It is simultaneously an ingredient — it has forms
with composition data and can be a line in a drink — and a recipe, with its own
steps in the body. A yield and a shelf life are both mandatory, and that is what
makes it a Preparation rather than a Component.

A Preparation is never transcluded. Referencing one produces a checklist line
and a cross-link, not inlined steps.
