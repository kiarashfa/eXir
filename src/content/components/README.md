# Components

Technique bundles, transcluded into a parent and fully flattened at build time:
"dry shake, then wet shake, double strain"; "swizzle to frost"; "bloom, then
pour in three additions".

One MDX file per component. Its steps and ingredient lines merge into the
parent so the reader gets one seamless page — step numbering, checklist and
timing all read as one drink.

Not for anything made ahead and used as an ingredient. That is a Preparation.
